Современный кроссплатформенный менеджер и панель администрирования для **выделенного сервера Project Zomboid** (полная поддержка **Build 41** и новейшего **Build 42+**).

Включает тактический десктопный интерфейс **Desktop GUI** (Windows и Linux) и легковесную удаленную веб-панель **Headless Web Dashboard** (FastAPI & WebSockets), оптимизированную для хостинга на Linux VPS / VDS без монитора.

---

## 🌟 Ключевые возможности

### 🌐 1. Два режима работы: Desktop GUI и Web-панель для VPS
* **Тактический Desktop GUI**: Построен на PyQt5 с премиальным темным glassmorphism-дизайном, фирменными шрифтами (`Inter` и `JetBrains Mono`) и отзывчивым управлением.
* **Современная веб-панель**: Работает на FastAPI и WebSockets. Позволяет управлять сервером со смартфона, ноутбука или браузера на выделенном Linux VPS без необходимости установки X11 или рабочего стола.
* **Мгновенный билингвальный переключатель (RU / EN)**: Переключение между русским и английским языками в один клик прямо из шапки приложения и веб-панели.

### 🎮 2. Живая консоль и управление игроками (Player Dashboard)
* **Интерактивный терминал в реальном времени**: Вывод логов сервера с настраиваемой автопрокруткой, цветовой подсветкой сообщений и полем отправки серверных команд.
* **Список игроков онлайн**: Автоматическое распознавание входов и выходов игроков по логам сервера.
* **Действия администратора в 1 клик**:
  * 👢 **Кикнуть игрока** (`kickuser`) с указанием причины.
  * 🚫 **Забанить игрока** (`banuser`) по никнейму или SteamID64.
  * 👑 **Выдать права Администратора** (`setaccesslevel admin`).
  * 📜 **Добавить в Whitelist** напрямую в SQLite базу данных сервера.
* **Панель быстрых команд**: Сохранение мира (`save`), включение дождя (`rain`), вызов вертолета (`chopper`) и отправка глобальных объявлений (`servermsg`).

### 🧟 3. Точная копия песочницы из игры 1:1 (`SandboxVars.lua`)
Разделена на 6 подвкладок, полностью повторяющих меню самой игры Project Zomboid:
1. **🧟 Зомби и Популяция**: Скорость (Спринтеры, Быстрые ходячие, Шатуны), Сила, Прочность, Способ заражения, Смертность, Воскрешение, Интеллект, Память, Зрение, Слух, Обоняние, Разложение, а также продвинутые настройки `ZombieConfig` (Множитель популяции, День пика, Респаун, Заваливание толпой, Выпад через забор, Размер и миграция орд).
2. **📦 Ресурсы и Лут**: 10 категорий редкости лута (Холодное оружие, Огнестрел, Патроны, Свежая еда, Консервы, Медикаменты, Литература, Снаряжение, Механика, Прочее), период респауна лута, отключение воды и электричества.
3. **🌍 Мир и Время**: Длина игровых суток (вплоть до 24 ч реального времени), стартовая дата и время, температура, осадки, скорость и дни эрозии природы, вертолет, мета-события, темность ночи и время с начала апокалипсиса.
4. **🚗 Транспорт**: Частота спавна автомобилей, исходное состояние, легкое управление (без ключа), дорожные пробки из разбитых авто, урон игроку при аварии, уровень топлива и сигнализации.
5. **👤 Персонаж и Навыки**: Множитель опыта с быстрым выбором (`1x`, `1.5x`, `2x`, `3x`, `5x`), свободные очки навыков, падение потребностей, питательность еды, скорость фермерства и расход топлива генераторами.
6. **🧩 Настройки модов**: Динамический редактор параметров модов с живым поиском. Автоматически парсит и отображает пользовательские таблицы модификаций (Brita, KI5, TrueActions и др.).

### ⚙️ 4. Полная конфигурация сервера (`servertest.ini`)
* Сетевые порты (`DefaultPort`, `UDPPort`, `SteamPort1`, `SteamPort2`, `RCONPort`).
* Настройка убежищ (убежища игроков или админов, вторжение, огонь, лут, респаун в убежище).
* Параметры безопасности (Авто-вайтлист при подключении, проверка контрольных сумм Lua, запрет входа под одним Steam ID, защита спавна, ограничение аккаунтов на игрока).
* Настройка встроенного голосового VOIP чата и глобального чата.

### 🧩 5. Менеджер модов Steam Workshop
* **Проверка совместимости с Build 41 и Build 42**: Цветовая маркировка (🟢 Проверен и совместим, 🟡 Универсальный, 🔴 Несовместим/Устарел).
* **Импорт коллекций Workshop**: Вставьте ссылку на коллекцию Steam или ID мода для мгновенного добавления.
* **Готовые сборки модов**: Автопарк (KI5), Арсенал (Brita), Набор QoL и Хардкор.
* **Порядок загрузки карт (Map Load Order)**: Удобное перемещение модовых карт выше стандартной карты *Muldraugh, KY*.

### 🛡️ 6. Сторожевой таймер и авто-перезапуск (Watchdog)
* Непрерывный фоновый мониторинг состояния игрового процесса.
* Автоматическое обнаружение краша сервера и запуск 10-секундного таймера авто-перезапуска.
* Защита от бесконечного цикла перезапусков при битых модах.
* Оповещения в **Discord Webhook** о запусках, остановках и сбоях сервера.

### 💾 7. Графический менеджер бэкапов и восстановление в 1 клик
* Полное резервное копирование в `.zip`: сохранения мира (`Saves/Multiplayer/`), файлы настроек (`Server/`) и база данных игроков (`db/`).
* Автоматический бэкап перед каждым стартом сервера.
* Окно управления бэкапами с информацией о размере, дате, кнопкой восстановления и удаления.

## 🚀 Инструкция по установке и запуску

### 🪟 Windows (Готовый EXE)
1. Скачайте [`PZ Server Manager.exe`](PZ%20Server%20Manager.exe) или запустите инсталлятор [`PZ_Server_Manager_Setup.exe`](PZ_Server_Manager_Setup.exe).
2. Запустите файл — все библиотеки и зависимости Python уже упакованы внутрь.

#### Запуск из исходного кода на Windows:
```cmd
setup.bat
run.bat
```

#### Запуск только веб-панели на Windows:
```cmd
run-web.bat
```

---

### 🐧 Linux Desktop (С графической оболочкой)
1. **Установите системные зависимости:**
   * **Ubuntu / Debian**:
     ```bash
     sudo apt update && sudo apt install -y python3 python3-venv python3-pip libxcb-xinerama0
     ```
   * **Arch Linux / Manjaro**:
     ```bash
     sudo pacman -S python python-pip
     ```
   * **Fedora**:
     ```bash
     sudo dnf install -y python3 python3-pip
     ```
2. **Настройка и запуск:**
   ```bash
   chmod +x setup.sh run.sh run-web.sh
   ./setup.sh
   ./run.sh
   ```

### 🖥️ Выделенный Linux VPS / VDS Сервер (Headless Web Panel)
Специальный серверный режим для VPS без монитора и без графического интерфейса.

#### Автоматическая установка через скрипт `setup_vps.sh` (в 1 команду):
```bash
git clone https://github.com/nmazarov/pz-server-manager.git
cd pz-server-manager
chmod +x setup_vps.sh
sudo ./setup_vps.sh
```

**Что делает скрипт автоматически:**
1. Устанавливает Java 17 JRE, 32-битные библиотеки SteamCMD (`lib32gcc-s1`) и Python 3.
2. Создает изолированное виртуальное окружение и устанавливает зависимости FastAPI & Uvicorn.
3. Запрашивает или генерирует пароль администратора для веб-панели.
4. Открывает необходимые порты в фаерволе `ufw`.
5. Создает и активирует фоновую службу **systemd** (`pz-web-manager.service`) с автозапуском при перезагрузке сервера.
6. Выводит в терминал готовую ссылку: `http://<IP-вашего-VPS>:8080`.

#### Управление службой на Linux VPS:
```bash
sudo systemctl status pz-web-manager   # Проверить статус службы
sudo journalctl -u pz-web-manager -f    # Просмотр логов в реальном времени
sudo systemctl restart pz-web-manager  # Перезапустить веб-панель
sudo systemctl stop pz-web-manager     # Остановить веб-панель
```

## 🌐 Сетевые порты и проброс портов (Port Forwarding)

Откройте следующие порты на вашем роутере или в панели хостинга (AWS, Hetzner, Selectel, Timeweb):

| Порт | Протокол | Назначение |
| :--- | :--- | :--- |
| **16261** | **UDP** | Основной игровой порт Project Zomboid |
| **16261** | **TCP** | Handshake авторизация |
| **16262** | **UDP** | Прямое подключение игроков |
| **8766** | **UDP** | Steam Master Server |
| **8767** | **UDP** | Steam P2P обмен |
| **8080** | **TCP** | Веб-панель управления сервером |

> [!TIP]
> В Windows нажмите кнопку **«🔓 Открыть порты»** в шапке приложения для автоматического создания правил в Брандмауэре Windows.
